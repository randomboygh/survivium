# Команды и права

Статус: ACTIVE (этап 7, 2026-11-06). Одна таблица прав — `Server.COMMANDS` в `src/server/server.gd`;
роль определяет сервер по ключу соединения (`Server.role_of`), каждый раз заново.

## Роли

| Роль | Кто | Как получает |
|---|---|---|
| игрок (`ROLE_PLAYER`) | все | по умолчанию; команд не даёт |
| хозяин (`ROLE_HOST`) | доверенный игрок | `op <кто>` владельца или терминала; `access.hosts` |
| владелец (`ROLE_OWNER`) | игрок, создавший сервер в игре | `Main._on_welcome` → `make_host`; `access.owners` |
| терминал (`ROLE_CONSOLE`) | консоль сервера и поле команд окна «Создать сервер» | процесс сервера, не сеть |

Списки хранятся в `access.json` папки мира. Снятая роль (`deop`) действует со следующей командой, без
перезапуска. Клиент роль не присылает: в протоколе нет поля роли.

## Команды

| Команда | Аргументы | Нужна роль | Что делает |
|---|---|---|---|
| `who` | — | хозяин | кто в мире, где |
| `say` | слова | хозяин | строка в чат всем от «Сервер» |
| `kick` | имя или номер | хозяин | отключить, персонаж уходит |
| `give` | кто, предмет (id, конец id, название), сколько 1–999 | хозяин | в сумку; запись в журнал безопасности |
| `tp` | кто, `x y z` (целые клетки) или к кому | хозяин | перенести |
| `ban`, `unban`, `bans` | имя или номер | хозяин | блокировка по ключу и имени |
| `whitelist` | `on`, `off`, `add <имя>`, `remove <имя>` | хозяин | пускать только своих; имя привязывается к ключу |
| `hosts` | — | хозяин | кто хозяева и владельцы |
| `security` | вид или имя | хозяин | последние записи журнала безопасности |
| `reload` | — | хозяин | перечитать данные модов с диска (горячая перезагрузка) |
| `help`, `?` | — | хозяин | список |
| `op`, `deop` | кто / имя | владелец | дать или снять роль хозяина |
| `stop` | — | владелец | сохранить и остановить сервер |
| `test` | `bot+`, `bot-`, `worlds`, `world <папка>`, `new [зерно]`, `new test`, `stop`, `hour` | на сервере с `--playtest` — любой игрок; на другом — хозяин (`stop` — владелец) | боты, другой мир сервера (имя папки под сохранениями, не путь), остановка, срок сервера для проверки (`TestCommands`, `PlaytestHost`) |

Команда в чате начинается с «/»; от игрока без роли — отказ и запись `command` в журнал; неизвестная —
«неизвестная команда»; без нужной роли — «только для владельца сервера». Каждая команда из чата пишется в
журнал сервера с именем и номером. Скрытых команд у сервера нет. На сервере для проверки (`--playtest`,
задаётся лишь в командной строке, `.github/workflows/playtest.yml`) «/test» и запрос `cheats` (настройки
страницы «Тестирование», `src/server/cheats.gd`: каждое значение проверено по типу и зажато в границы)
доступны любому игроку; на любом другом — только хозяину, игроку без роли `test` отвечает отказом, `cheats` —
false (`Requests.may_cheat`).

## Как добавить команду

1. Ветка в `match` функции `Server.command` (аргументы — строки: проверить число и границы).
2. Строка в `COMMANDS` с ролью; без неё команда считается неизвестной.
3. Строка в `help` и в таблице выше; проверка в `tests/unit/security_test.gd` `_test_commands`.
