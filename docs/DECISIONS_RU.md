# Архитектурные решения

Английская версия: [DECISIONS.md](DECISIONS.md) (она основная, эта — копия).

Статус: ACTIVE. Индекс решений, на которых держится код. Полный журнал (№ 1–185, в том числе
геймдизайн) — таблица «Журнал решений» в `plan/README.md` библиотеки; номера ниже — оттуда. Новое
решение сначала записывается в журнал, сюда — если оно меняет принцип кода. Где причина не записана,
так и сказано.
