# Архитектурные решения

Статус: ACTIVE. Индекс решений, на которых держится код. Полный журнал (№ 1–152, в том числе
геймдизайн) — таблица «Журнал решений» в `plan/README.md` библиотеки; номера ниже — оттуда. Новое
решение сначала записывается в журнал, сюда — если оно меняет принцип кода. Где причина не записана,
так и сказано.

| Решение | Проблема | Причина | Последствия | Статус | Где |
|---|---|---|---|---|---|
| Godot 4, только GDScript (№ 1) | движок для web, Android, ПК и сервера | GDScript работает во всех целевых сборках; C# в web-экспорте Godot 4 нет | горячие места сервера при нужде — GDExtension; в браузере только GDScript | действует | `plan/architecture/overview.md` |
| Рендерер Compatibility, web без потоков | игра в браузере телефона | WebGL 2; без потоков хостингу не нужны заголовки COOP/COEP | нет тяжёлых эффектов (SDFGI, объёмный туман); лимит огней на объект; шейдеры прогреваются вручную | действует | `project.godot`, `plan/architecture/overview.md`, [systems/rendering.md](systems/rendering.md) |
| Авторитетный сервер, WebSocket, моды только на сервере (№ 2) | многопользовательская игра | честность: клиент шлёт намерения, сервер решает | правила отделены от клиента; сервера пока нет | принято, не сделано | `plan/architecture/networking.md` |
