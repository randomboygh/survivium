# Интерфейс и настройки

Английская версия: [ui.md](ui.md) (она основная, эта — копия).

Статус: ACTIVE.

Эта страница — обзор; подробности разнесены по темам в `ui/`. Прочтите обзор, затем только ту страницу, которой
касается изменение (если она длинная — сначала `grep -n '^#' docs/systems/ui/<page>.md`).

**Назначение.** Пиксельный интерфейс по макетам: главное меню над нарисованным пейзажем и экран загрузки, «Новый мир» и
«Загрузить мир», HUD (часы, срез уровней, панель, кнопки), окно сумки с крафтом и сундуками, карты, экран смерти,
настройки и страница «Тестирование», панель производительности и журнал фризов. Раскладка
подстраивается под пропорции экрана и переключается между сенсором и мышью по последнему вводу.
