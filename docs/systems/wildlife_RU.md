# Звери

Английская версия: [wildlife.md](wildlife.md) (она основная, эта — копия).

Статус: ACTIVE.

**Назначение.** Животные мира. Вид задаёт только свойства; кто кому еда и угроза, выводят общие правила.
Звери появляются вокруг людей, бродят, пасутся, отдыхают вне своих часов, убегают от угроз, охотятся
голодными; стаи идут за вожаком, летуны ночуют в кронах, лазающие ходоки забираются на деревья, пловцы
держатся открытой воды, вид с `biomes` появляется только на своей земле.

**Где смотреть.** Эта страница — обзор; файлы и подробности разнесены по темам в `wildlife/`: читайте только
ту страницу, которой касается изменение.

**Кто использует.** Сеанс мира (`session.gd`: создаёт, `start_wildlife` после готовности мира, шаг
`step_wildlife` каждый кадр из Main), `player_link.gd` (события для клиента); копию — `creatures.gd`,
`voices.gd`, следы, `fire_shadows.gd` (тени зверей у огня); тесты и `tools/shot.gd` пишут в
`main.session.wildlife`.

**Ограничения.** Ходок не достаёт пловца и наоборот, летун достаёт обоих. Биом столбца берётся из
`gen.lay_out`. Ныряет только рыба (см. «Глубина»); сторона зверя у клиента выводится из его движения, сервер её
не знает. Голоса бандл приносит готовыми `.wav` (синтез — таблица в `tools/make_sounds.gd`).

**Тесты.** `tests/unit/wildlife_test.gd` (`ai_relations`, `wildlife`, `climbers`, `biomes`, `swimmers`,
`fishing`, `birds`, `shore`, `jostle`, `hunting`, `fire`, `taming`, `attacks`; стая ждёт тактов мышления, а не
порядка случайных чисел); рисованные: `tests/unit/view_test.gd` (`animal_flinch`, `boar_states`: кадры кабана и
его тело, `fox_states`: лисы, `grouse_states`: взмахи крыльев и шаги тетерева, `deer_states`: оленя).

**Подробнее.** `plan/design/creatures-ai.md`; `plan/architecture/ai.md` — замысел движка поведения
(формулы помечены как черновик, в коде проще).
