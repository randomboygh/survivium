# Интерфейс и настройки

Статус: ACTIVE.

**Назначение.** Пиксельный интерфейс по макетам: главное меню поверх живого мира, «Новый мир» и «Миры»,
HUD (часы, срез уровней, панель, кнопки), окно сумки с крафтом и сундуками, карты, экран смерти,
настройки и страница «Тестирование», панель производительности и журнал фризов. Раскладка
подстраивается под пропорции экрана и переключается между сенсором и мышью по последнему вводу.

**Файлы** (`src/client/ui/`, кроме отмеченных)
- Экраны: `main_menu.gd` (первый экран над миром сохранённого зерна; `main.restart()` перезагружает
  сцену), `world_setup.gd` («Новый мир»: зерно, вид мира, настройки генератора с картой, страница
  «Моды»: под выпавшим бандлом — вся цепочка причины, `Mods.why`), `world_list.gd` («Миры»), `death_screen.gd`.
- Игра: `hud.gd` (главный экран), `inventory_window.gd` и `craft_panel.gd` (сумка, сундук, станок,
  крафт), `vitals_panel.gd`, `body_feedback.gd`, `sound_marks.gd` (метки направления звуков),
  `vibration.gd`.
- Карты: `minimap.gd` (карта красится по чанку в регионы по 32 чанка, хранится в сохранении;
  `shaders/map_ground.gdshader`), `map_view.gd` (на весь экран), `src/client/game/markers.gd` (маркеры
  игрока; телепорт со страницы «Тестирование»).
- Настройки: `src/client/settings.gd` (сохранённые настройки и переключатели «Тестирования»: каждый
  модуль читает свои значения там), `settings_menu.gd` (страницы строк «название ‹ значение ›»; версия и
  «Что нового» из `build_info.json`).
- Отладка: `perf_panel.gd` (F3), `freeze_log.gd` и `gl_watch.gd` (журнал фризов: части игры, движок,
  отрисовка, страница браузера и сборка мусора, собранные шейдеры, данные в GPU), `src/client/view/draw_census.gd`;
  «Данные для теста» (`SettingsMenu.report_text`): сборка, мир, место, время, погода, настройки, устройство и
  «Загрузка» — запуск до сцены игры, записи модов, их чтение и загрузка (`Content.read_ms`, `load_ms`), мир.
- Общее: `ui_style.gd` (панели, рамки, кнопки, шрифт), `item_icons.gd` (картинки предметов
  `icons/<icon>.png` 12×12 и значки `assets/ui/`), `hotbar_slot.gd`, `icon_tabs.gd`, `tab_row.gd`,
  `fact_chips.gd`.

**Данные.** Тексты интерфейса по-русски в коде UI; картинки предметов — у их бандлов; советы загрузки —
`MainMenu.TIPS`.

**Подводные камни**
- После получения новых ассетов (шрифты, текстуры) снова запустите `--import`, иначе скрипты HUD падают
  с ошибками null, похожими на ошибки кода.
- JS-фрагмент из GDScript должен быть строгим и не трогать `arguments` в обёртке с именованными
  параметрами: это создаёт объект на каждый вызов (`gl_watch.gd`).
- Касание в браузере приходит и как движение мыши (см. [interaction.md](interaction.md)).
- Пока прогреваются шейдеры, HUD скрыт меню; элементы интерфейса для прогрева — на холсте мира.

**Тесты.** Юнит-тестов интерфейса нет; `tests/browser_smoke.mjs` открывает сборку в Chrome как ПК и как
телефон (DPR 3, касания) и падает на SCRIPT ERROR / Parse Error; скриншоты `tools/shot.gd`
(`--phone` — раскладка телефона).
