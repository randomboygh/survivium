# Сеанс мира и правила игры

Статус: ACTIVE (этапы С1–С2.1 сервера, решение 153; план `plan/architecture/server.md`).

**Назначение.** Одна точка, которая держит мир с правилами над ним и персонажей в нём и делает тик: то,
что на сервере будет крутиться 20 раз в секунду, а на клиенте идёт по шагам между делами кадра. Правила
игры, которые хозяин сервера задаёт всем (свободная стройка, износ, мгновенный крафт), — отдельный объект,
который правила читают как есть.

**Файлы**
- `src/shared/game/session.gd` — сеанс: берёт мир, генератор, часы, правила и вещи на клетках, сам делает
  `WorldActions`, `Storms`, `Wildlife`; `add_player(who, workshop)` / `remove_player(who)` (персонаж
  получает мир, часы и вещи; звери видят персонажей как людей); `start_wildlife(seed)`; `tick(delta)` =
  `step_clock` (время и погода; погода чувствуется у первого игрока, пока нет климата по районам) →
  `step_players` (каждый персонаж и его мастерская, шаг не больше `STEP_MAX` 0,05 с) → `step_wildlife`
  (звери вокруг всех игроков) → `step_storms` (ветер вокруг игроков по очереди); `push_on(who)` — чем
  звери толкнули игрока.
- `src/shared/game/rules.gd` — правила игры: `free_build`, `tool_wear`, `instant_craft`; `of(dict)`,
  `to_dict` / `from_dict`. На клиенте их ставит страница «Тестирование» (`Settings.apply`), сервер возьмёт
  из конфига.
- `src/client/main.gd` — создаёт правила в `_ready`, сеанс в `start_world` (когда есть мир) и вызывает его
  шаги в `_process` между своими делами, чтобы панель F3 различала их; `actions`, `storms`, `wildlife`
  Main — ссылки на сеансовые.

**Кто использует.** Main, `tools/profile.gd` (шаги по отдельности), тесты. Остальной клиент читает
`game.actions`, `game.wildlife`, `game.storms`, `game.rules`, как раньше, а просит у правил через
`game.net` — запросами протокола к серверу внутри игры ([network.md](network.md), С2.1).

**Ограничения.** Тело игрока двигает клиент (`player.gd`), не сеанс: по решению 153 сервер проверит
движение тем же `body.gd` и поправит. Чанки заказывает `chunk_streamer.gd` клиента, не сеанс (этап С2).
Пауза меню останавливает и сеанс (`get_tree().paused`): на сервере мир не встанет (С2). Число зверей
каждого вида общее на мир (`Wildlife.wanted`), новые появляются у случайного игрока. Погода с улицы
(`real_weather.gd`) пока клиентский узел в общей папке (переедет в `src/server/` на С3).

**Тесты.** `tests/unit/session_test.gd` (`rules`: словарь и обратно, свободная стройка; `session`: тик
двигает время, обоих персонажей и обе мастерские, звери у обоих игроков, ветер по очереди, толчки, уход
игрока); `tests/unit/body_test.gd` (формы вещей, прочитанные сеансом из моделей, совпадают с моделями).
