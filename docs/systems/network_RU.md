# Протокол и сервер

Английская версия: [network.md](network.md) (она основная, эта — копия).

Статус: ACTIVE (этапы С2.1–С6 сервера, решение 153; план `plan/architecture/server.md`).

Эта страница — обзор; подробности разнесены по темам в `network/`. Прочтите обзор, затем только ту
страницу, которой касается правка (если она длинная, сначала `grep -n '^#' docs/systems/network/<страница>_RU.md`).

**Назначение.** То, что клиент просит у правил, идёт сообщениями: запрос `[вид, номер, аргументы]`, ответ
`[номер, значение]`; то, что одна сторона сообщает другой без ответа, — событие `[вид, аргументы]`. Байты —
`var_to_bytes` без объектов. Персонаж и мастерская игрока живут на сервере (`src/server/player.gd`), вещи,
часы и звери — в сеансе сервера; на клиенте — их копии, которые кормит `Mirror`. В одиночной игре те же байты
идут через петлю в своём процессе (`LocalHost`, сервер внутри игры); по сети — через WebSocket к серверу из
терминала (`--server`, вход по `--join ws://…` или «Присоединиться» в меню). Клиент играет через протокол
всегда. Сервер ничему из присланного сокетом не верит: проверяются досягаемость, права на землю, типы и
границы каждого аргумента, запросы делаются по одному, номер не выше последнего второй раз не делается.
