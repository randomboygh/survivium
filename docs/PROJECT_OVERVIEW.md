# Обзор проекта

Статус: ACTIVE, сверено с кодом 2026-10-30 (клиент 0.2.235).

## Игра

Survivium — медитативная песочница выживания: большой процедурный мир по уровням в 3D pixel-art с
видом 3/4, один персонаж, добыча, крафт, стройка, живой мир со зверями и сезонами, позже командный
PvP и территории. Работает в браузере, позже на Android; многопользовательская игра через свой
авторитетный сервер (его ещё нет). Замысел: `plan/design/overview.md` и `plan/design/mvp-design.md`
в библиотеке; что сделано по областям — `README.md` в корне.

## Состояние

- Этап 0 (технический прототип) закрыт, идёт этап 1 (MVP), см. `plan/mvp.md`. Сейчас это одиночная игра
  в браузере: https://randomboygh.github.io/survivium/ (собирается из `main`).
- Сделано: мир без края из шума (48 уровней, горы, пещеры, реки, болота, 13 биомов как данные), время,
  сезоны и 11 видов погоды, персонаж с сумкой, силами и смертью, работа руками (копать, строить, рубить,
  косить, собирать, сажать), крафт у станков с очередью, 16 видов зверей, звук и музыка из нот,
  сохранение по мирам, моды и бандлы (каждый зверь, растение, инструмент, биом включается отдельно).
- В данных сейчас: 13 материалов ячеек, 56 предметов, 28 рецептов, 15 пород деревьев, 5 кустов,
  12 растений на траве, 17 существ (с человеком), 13 биомов; 9 модов, 82 бандла.
- Нет: сервера и сети, территорий и PvP, редактора, NPC, Android-сборки, скриптов модов. Места под них
  в коде нет, есть только замыслы в `plan/`.

## Технологии и ограничения

- Godot 4.5.1, рендерер GL Compatibility (WebGL 2), web-экспорт без потоков, чистый GDScript:
  скрипты подключаются константами `preload`, `class_name` не используется, автозагрузок и плагинов нет.
- Телефонный браузер примерно в 10 раз медленнее компьютера, поэтому ничего размером с карту или чанк
  не делается за один кадр (задания по столбцам и рядам в бюджете кадра, `tests/frame_test.gd`).
- CI рендерит программно: его FPS ничего не значит, цифры даёт только телефон пользователя (F3).
- Всё, что описывает контент, — данные модов (`content/<мод>/…/data/*.yaml`), а не константы кода;
  код просит контент по роли, а не по id (кроме id ядра `core:`).
- Правила игры (`src/shared/`) отделены от картинки и ввода (`src/client/`), чтобы их запустил сервер.
- Язык: интерфейс, README и документы в `docs/` и `plan/` по-русски; код, комментарии, коммиты и PR
  по-английски.
