# Перевод Survivium

Статус: ACTIVE. Как переводится текст игры: ключи, новый язык, перевод игры и мода, что не переводится
никогда. Сторона кода — [systems/lang.md](systems/lang.md); английская версия этого руководства —
[TRANSLATION.md](TRANSLATION.md) (она основная, эта — копия).

## Как устроено

- Игра на десяти языках (решение 183): английский (по умолчанию), русский, испанский, португальский,
  французский, немецкий, итальянский, польский, турецкий, украинский. При первом запуске — язык устройства,
  если он есть в списке; сменить — «Настройки» → «Игра» → «Язык».
- Каждый текст, который читает игрок, — **ключ** в квадратных скобках (решение 186): маленькие латинские
  буквы, цифры, `_` и `.` — `"[bag_is_full]"`, `"[small_map]"`. В коде и данных модов только ключи; каждый
  язык, и английский тоже, сопоставляет ключу свой текст. Текст, который не ключ (имя игрока, надпись на
  табличке), показывается как написан.
- Перевод — плоский словарь YAML в файле `lang/<код>.yaml` рядом с тем, что он переводит:

  ```yaml
  "[new_world]": "Новый мир"
  "[bag_slots_taken]": "Сумка: занято %d из %d ячеек"
  ```

  | Что | Где его переводы |
  |---|---|
  | интерфейс и правила ядра (все ключи `src/`), классы инструментов `[tool.<класс>]` | `content/core/lang/<код>.yaml` |
  | описание мода (`mod.yaml`: название и описание) | `content/<мод>/lang/<код>.yaml` |
  | записи и описание бандла (вещи, звери, рецепты…) | `content/<мод>/<бандл>/lang/<код>.yaml` |

- Ключ, которого в языке нет (или он пустой), показывается по-английски; нет и английского — показывается
  сам ключ, `[bag_is_full]`, и пропуск сразу виден.
- Английский и русский должны быть полными (CI, `--strict en,ru`); остальные языки могут отставать.

## Ключи данных мода

`title` и `description` записи — тоже ключи, по имени записи:

| Поле | Ключ |
|---|---|
| название записи | `[<мод>.<вид>.<id>]` — `[tools.items.stone_axe]`, `[animals.creatures.wolf]` |
| описание записи | то же с `.about` — `[tools.items.stone_axe.about]` |
| название мода (`mod.yaml`) | `[<мод>.mod]`, описание `[<мод>.mod.about]` |
| название бандла (`bundle.yaml`) | `[<мод>.<бандл>.bundle]`, описание `….about` |

`<вид>` — имя файла данных (`items`, `recipes`, `creatures`…). У рецепта и вещи, которую он делает, два
ключа, обычно с одним текстом. Класс инструмента (`tool: knife`) в подсказках называется ключом
`[tool.knife]`; мод со своим классом приносит этот ключ в свой `lang/`.

## Слова с формами

Одно английское слово может быть двумя в другом языке (род, форма числа): это два ключа, `[small_ui]` и
`[small_map]` («мелкий» и «маленькая»), оба «small» по-английски. Существительное при числе — три ключа,
на один, два и пять: `[block_1]`, `[block_2]`, `[block_5]` («блок», «блока», «блоков»). Язык с двумя
формами заполняет `_2` как `_5`.

## Перевести игру на язык из списка

1. Что не переведено: `python3 tools/lang_check.py --missing de` (JSON: ключ → файл). Английский
   (`en.yaml`) рядом с каждым файлом — текст для перевода, русский (`ru.yaml`) — второе прочтение смысла.
2. Дописать недостающие ключи пустыми: `python3 tools/lang_check.py --write de`.
3. Заполнить пустые значения. Все `%s`, `%d`, `%.1f` английского сохранить в том же порядке (`%` в Godot
   только позиционный); `%%` (знак процента) можно переставлять. Кавычки — по обычаю языка («», “”, „“), не
   ASCII `"` внутри значения.
4. Проверить: `python3 tools/lang_check.py` (ошибка при сломанном файле или неверном `%`). Посмотреть в игре:
   `tools/shot.gd -- --lang de` снимает скриншоты на этом языке.

## Добавить новый язык

1. Добавить язык в `Lang.LANGS` в `src/shared/content/lang.gd` (код и самоназвание, как его покажет строка
   «Язык») и в `LANGS` в `tools/lang_check.py`.
2. `python3 tools/lang_check.py --write <код>` создаст пустые файлы везде; заполнить, как выше.
3. В пиксельном шрифте должны быть буквы языка (`assets/fonts/`); проверить по скриншотам.

## Перевести мод

Мод (или его бандл) несёт свои переводы: `lang/<код>.yaml` рядом с его `mod.yaml` или `bundle.yaml`, с
ключами его записей и описания, сначала английский. `python3 tools/lang_check.py --write en` создаёт
пустые файлы и для мода в `content/`. Название обычным текстом вместо ключа показывается как написано на
любом языке (для модов этого репозитория проверка считает это ошибкой).

Моды сборки для ПК лежат открытыми файлами в `content/` рядом с программой (решение 186): перевод можно
править прямо там, игра подхватит его сразу (горячая перезагрузка).

## Что не переводится никогда

Внутренние тексты пишутся по-английски обычным текстом, не ключами, и такими остаются (решение 186):
журнал, консоль и ответы команд сервера, журнал безопасности, панель статистики (F3) и её метки, журнал
фризов, время загрузки, разбор вызовов отрисовки, отладка ИИ и «Данные для теста».

## Правила для кода, который показывает текст

- Текст для игрока — ключ: `"[bag_is_full]"`, а не фраза по-английски или по-русски (проверка падает на
  русском тексте в коде). Новый ключ — в `content/core/lang/en.yaml` и `ru.yaml` в том же коммите:
  `python3 tools/lang_check.py --write en` и `--write ru`, затем заполнить.
- Сервер не переводит: отдаёт ключ или `Lang.line(ключ, [значения])`, клиент переводит на язык игрока.
  Значение-ключ (название вещи) тоже переводится.
- На клиенте ключ со значениями — `Lang.f(ключ, значения)`, не `ключ % значения` и не склейка кусков:
  порядок слов в языках разный. Вариант с куском и без — два ключа.
- Текст для Label (уведомления, строка загрузки) — ключ или `Lang.line`: Label переводит сам. Коду, которому
  нужны сами слова (измерить, сделать букву строчной), — `Lang.t(ключ)`.
- Поменять английский текст — поменять только `en.yaml`: ключ остаётся, и переводы тоже (сверить их с
  новым смыслом).
