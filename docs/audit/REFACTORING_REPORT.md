## Что исправлено (шаг 3)

- Сохранения: сбой или пустая запись чанка, карты или json больше не заменяет старый файл
  (`WorldStore._written`); старые id растений на газоне и предметов в мешках приводятся к нынешним при
  загрузке; тестовый мир выбирает место появления после того, как знает уровень земли.
- Контент: запись с уже занятым id оставляет первую; поля `mod`/`bundle` в записи — неизвестные поля;
  YAML не считает апостроф внутри слова началом кавычек и не принимает повтор ключа в `{…}`.
- Сеть: полёт подобранной вещи видит только взявший; повторный вход не шлёт старую очередь; ушедший
  игрок сохраняется; «воскреснуть» может только мёртвый; типы полей INPUT и настройки сервера
  проверяются.
- Клиент: сервер из меню сохраняет мир при закрытии окна и уходе в фон; сбор берёт ближайший предмет;
  настройки вне диапазона отбрасываются; колесо мыши переходит с первого слота на последний; шапка
  над стволом и пена воды в шейдерах; помеченный к перестройке чанк больше не теряется; центр кроны без
  точек; модели вещей кэшируются по точке опоры; окна интерфейса уходят из дерева сразу.
- Тесты: ошибка скрипта (SCRIPT ERROR) теперь проваливает `run_tests.gd` и `run_all.sh`; тесты пишут
  свои `test_settings.cfg` / `test_server.cfg`, а не настройки игрока; генераторы картинок и звуков без
  имён ничего не перезаписывают (`--all` — всё).

## Что переработано (шаг 4)

- Весенний сброс (ягоды, ветки, семена, скошенная трава) — правило сеанса: `Session` подключает его к
  часам мира. Выделенный сервер раньше не делал его вовсе; загрузка весеннего сохранения сбрасывала
  собранное (повод перезаходить за ветками) и показывала «Наступила …»; клиент по сети менял свою копию
  мира.
- `Content.available / bundles_of / all_bundles` читают один скан папки `content/` вместо диска на
  каждый вызов; `Content.generation` и `Mods._built` не дают реестрам остаться со старыми массивами;
  `resolve` — алгоритм Кана с тем же порядком; `Mat.of_role` — по таблице.
- `main.gd`: `_attach_world` и `_watch_actions` общие для своего мира и мира сервера.
- UI: `_show_screen` главного меню, `UiStyle.accent`, `UiStyle.well`, `Protocol.build_info`.
- Тесты: файл юнит-теста не из `FILES` — провал; `Protocol.INPUT_SIZE` и проверка, что раскладку INPUT
  клиента сервер принимает; тесты старых сохранений с другим порядком материалов; `doc_index.py uses`
  видит сцены.

## Риски для пользователя

- Весенний сброс теперь работает и на выделенном сервере: весной ягоды, ветки и скошенная трава
  отрастают там впервые. Это исправление, но игроки сервера его заметят.
- Сохранение мира после сбоя записи: если диск полон, игра пишет ошибку и оставляет старый файл
  (раньше файл мог стать пустым).
- Тени факела и костров теперь пишутся только при смене: если на телефоне тень огня перестанет
  обновляться при смене режима «Тени огня», это отсюда (проверка: ночь, факел, переключить режим).
- `tools/make_*.gd` без имён теперь ничего не делают: нужен `--all`.
