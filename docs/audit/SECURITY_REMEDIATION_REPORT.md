## Остаётся

1. **`ws://` без шифрования** (S-20) в локальной сети: ключ и пароль видны тому, кто слушает сеть. Через
   туннель — `wss://`. Сделать: свой сертификат на сервере (`TLSOptions`) — нужен выбор хозяина.
2. **Нет учётных записей** (S-22): ключ — единственное удостоверение, открыто в `user://servers.cfg`;
   бан по имени обходится сменой имени, по ключу — новым ключом. Полноценные аккаунты — отдельная задача.
3. **Допуск движения** 2,5 клетки оставлен ради задержки сети: в его пределах тело может стоять чуть не там,
   где позволяет физика (сквозь стену — нет). Ужесточать только по замерам с телефона.
4. **Ограничения по адресу за туннелем** общие для всех (все с этой машины): перебор пароля задерживает
   новых игроков, не тех, у кого есть ключ.
5. **Права хозяина**: `give`, `tp`, `ban`, `kick`, `say` у хозяина по `op` остались — он доверенный.
6. Земля красится издалека (по замыслу, окно земли); вещи бросаются по одной (нагрузка ограничена сумкой).
