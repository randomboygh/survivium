## Что проверено

Вся цепочка: сокет и приём кадров (`Server.poll`, `_take`, `_hello`), разбор (`Protocol.decode`),
каждый запрос `Requests._rule` и правило, до которого он доходит (`WorldActions`, `Placed`, `Plans`,
`Workshop`, `CraftQueue`, `Inventory`, `Character`, `Teams`, `Territory`, `Fights`), `input` и проверка
движения (`Player.take_input`, `body.gd`), чат и команды (`Server._on_chat`, `command`), вход, ключи,
баны, белый список, сохранение игроков (`ServerStore`), туннель. Исходное состояние: ветка от `main`
62e2911, `run_tests` 3369 проверок без падений.

Уже было сделано хорошо: результат всех действий считает сервер; аргументы проверяются по типам;
повтор номера запроса не делается дважды; запросы выполняются по одному целиком (двое не удвоят стопку);
досягаемость руки для сундуков, вещей и вещей на земле; права земли; ключ — случайные 16 байт, на диске
только хеш; `bytes_to_var` без объектов; сохранение одним снимком (вещь между сундуком и сумкой не
двоится); чат на клиенте — `Label`, без разметки.
