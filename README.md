# Survivium

Медитативная песочница выживания: процедурный мир по уровням в стиле 3D pixel-art,
работает в браузере и на Android, клиент-сервер. План и геймдизайн ведутся отдельно
(папка `plan/` в файлах проекта).

## Текущее состояние: технический прототип (этап 0)

Проверяем, что 3D pixel-art тянет браузер и телефон:

- остров 128×128 ячеек и 20 уровней, сгенерированный по seed (холмы, скалы, пещеры, руда, лес, вода);
- рендер в низком разрешении (~360 px по высоте) без сглаживания, камера 3/4 с привязкой к пикселям;
- срез верхних уровней, когда персонаж под крышей или в горе, ручной срез клавишами Q / E;
- копание и установка блоков, перестройка мешей;
- день и ночь, 4 сезона (оттенок листвы и травы, снег, лёд на воде), дождь и снегопад
  шейдером поверх одной текстуры;
- воксельные кусты и сундук (16 вокселей на ячейку);
- звери, поведение которых выводится из свойств вида (заяц, белка, кошка, олень, волк).

### Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить |
| Пробел | прыжок |
| ЛКМ / ПКМ | копать / поставить блок |
| 1–7, колесо | выбрать блок |
| Q / E | срез уровней вниз / вверх |
| Z | следующий сезон |
| X | осадки |
| T | ускорить время |
| G | тени вкл/выкл |
| H | скрыть подсказку |

На сенсорном экране: джойстик слева, кнопки справа, касание копает или ставит блок.

## Разработка

- Движок: Godot 4.5 (рендерер Compatibility, чтобы работать в браузере).
- Открыть проект: Godot → Import → `project.godot`.
- Тесты: `godot --headless --path . --script res://tests/run_tests.gd`.
- GitHub Actions на каждый пуш запускает тесты, собирает web-версию и публикует её на GitHub Pages
  (в настройках репозитория: Settings → Pages → Source: GitHub Actions).

### Структура

- `src/shared/`: данные мира, генератор, правила поведения, рейкаст (общее для клиента и будущего сервера).
- `src/client/`: рендер чанков, текстуры, спрайты, игрок, звери, интерфейс.
- `shaders/`: шейдеры мира (срез, снег, мокрость, сезоны) и воды.
- `tests/`: headless-тесты.
