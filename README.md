# Survivium

Медитативная песочница выживания: процедурный мир по уровням в стиле 3D pixel-art,
работает в браузере и на Android, клиент-сервер. План и геймдизайн ведутся отдельно
(папка `plan/` в файлах проекта).

## Текущее состояние: технический прототип (этап 0)

Проверяем, что 3D pixel-art тянет браузер и телефон. Играть: https://randomboygh.github.io/survivium/
(собирается из `main` на каждый пуш).

- тестовый остров 384×384 ячеек и 40 уровней по seed: холмы, плато, скалы, пещеры, озеро, река, ручей,
  болото, лес, берег; ячейка 8 px (полметра), персонаж около двух ячеек ростом;
- рендер в низком разрешении (~360 px по высоте) без сглаживания, точная косоугольная проекция 3/4:
  один тексель равен одному пикселю, картинка масштабируется только целым числом;
- склоны мягкого грунта, скосы углов в плане под 45°, обрывы у камня;
- срез верхних уровней под крышей и в горе, ручной срез (Q / E), уровни выше и ниже полупрозрачны,
  силуэт персонажа за препятствием;
- копание и установка блоков; меши чанков строятся по столбцу ячеек в пределах бюджета кадра,
  поэтому ни копание, ни подгрузка мира не дают фризов;
- стиль в духе t3ssel8r: кромки граней, переходы материалов, ступенчатый свет, тени облаков, трава
  с ветром, ель и дуб с одной тенью на крону, ягодные кусты, вода с пеной (вброд, вплавь, лёд),
  костёр, светлячки, листопад, цветокор по времени суток, сезону и погоде;
- день и ночь, 4 сезона, дождь и снег шейдером поверх одной текстуры, снег и дождь только под
  открытым небом (карта крыши), сугробы и следы;
- звери, поведение которых выводится из свойств вида (заяц, белка, кошка, олень, волк);
- пиксельный интерфейс по макетам (plan/design/ui.md): время, срез уровней, панель с руками и блоками,
  меню паузы, статистика производительности (F3); раскладка подстраивается под пропорции экрана и
  переключается между сенсором и мышью по последнему вводу.

### Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить |
| Пробел | прыжок |
| ЛКМ / ПКМ | копать / поставить блок |
| 1–7, колесо | выбрать блок |
| Q / E | срез уровней вниз / вверх |
| R | вернуть срез к уровню игрока (на экране — тап по номеру уровня) |
| Z | следующий сезон |
| X | осадки |
| T | ускорить время |
| G | тени вкл/выкл |
| H | скрыть подсказку |
| F3 | статистика производительности |
| Esc | меню паузы (там же сезон, осадки, время, тени) |

На сенсорном экране: джойстик слева, справа кнопка действия (копать / ставить) и прыжок,
касание мира делает действие руки, выбранной на панели. Кнопка с графиком вверху открывает
статистику (FPS, время кадра, фризы, просадки, отрисовка), кнопка меню ставит игру на паузу.

## Разработка

- Движок: Godot 4.5.1, рендерер Compatibility (чтобы работать в браузере), чистый GDScript.
- Открыть проект: Godot → Import → `project.godot`.
- Тесты: `godot --headless --path . --import`, затем `godot --headless --path . --script res://tests/run_tests.gd`.
- GitHub Actions (`.github/workflows/build.yml`) на каждый пуш и PR запускает тесты, собирает web-версию,
  проверяет её в Chrome (`tests/browser_smoke.mjs`, в том числе как телефон с сенсором) и из `main`
  публикует на GitHub Pages.
- Правила для разработки и известные подводные камни: [CLAUDE.md](CLAUDE.md).
- План и геймдизайн: папка `plan/` в файлах проекта Claude (оглавление и журнал решений в `plan/README.md`).

### Структура

- `src/shared/`: данные мира (`world_data.gd`), генератор (`world_gen.gd`), материалы, деревья, кусты,
  правила поведения зверей, рейкаст. Не зависит от клиента: это основа будущего сервера.
- `src/client/`: всё, что рисует и слушает ввод. `main.gd` собирает сцену и ведёт игру;
  `chunk_mesher.gd` и `foliage.gd` строят меши чанков и растения; `pixel_view.gd` отвечает за
  пиксельную проекцию; `player.gd`, `creatures.gd`; эффекты, следы, сугробы, карта крыши;
  интерфейс (`hud.gd`, `ui_style.gd`, `perf_panel.gd`, сенсорные кнопки и джойстик).
- `shaders/`: шейдеры мира, воды, травы, крон, теней, спрайтов, частиц и цветокора; общий код и сдвиг
  проекции 3/4 в `common.gdshaderinc`.
- `assets/fonts/`: пиксельный шрифт Press Start 2P (лицензия OFL).
- `tests/`: headless-тесты (`run_tests.gd`) и проверка сборки в браузере (`browser_smoke.mjs`).
- `tools/`: скриншоты сцен без браузера (`shot.gd`), карта острова сверху (`map.gd`), замеры
  генерации, мешей и правок (`bench_gen.gd`, `bench_mesh.gd`, `bench_edit.gd`).

Скриншоты сцен (день, вечер, ночь, дождь, осень, зима, пещера, берег и другие):
`xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 --script res://tools/shot.gd -- /tmp/shots [имена]`.
