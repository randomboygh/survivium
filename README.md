# Survivium

Медитативная песочница выживания: процедурный мир по уровням в стиле 3D pixel-art,
работает в браузере и на Android, клиент-сервер. План и геймдизайн ведутся отдельно
(папка `plan/` в файлах проекта).

## Текущее состояние: технический прототип (этап 0)

Проверяем, что 3D pixel-art тянет браузер и телефон:

- остров 128×128 ячеек и 20 уровней, сгенерированный по seed (холмы, скалы, пещеры, руда, лес, вода);
- рендер в низком разрешении (~360 px по высоте) без сглаживания, точная проекция 3/4: верх ячейки и её
  стена ровно 16×16 пикселей, один тексель равен одному пикселю, камера скользит плавно;
- срез верхних уровней, когда персонаж под крышей или в горе, ручной срез клавишами Q / E;
- копание и установка блоков, перестройка мешей;
- визуальный стиль в духе t3ssel8r: светлые и тёмные кромки граней, переходы материалов, ступенчатый свет,
  тени облаков, трава с ветром, кроны из листовых шапок, вода с пеной и рябью, костёр с частицами и
  светом, светлячки, листопад, цветокор по времени суток, сезону и погоде;
- день и ночь, 4 сезона (оттенок листвы и травы, снег, лёд на воде), дождь и снегопад
  шейдером поверх одной текстуры;
- ягодные кусты, воксельные сундук и костёр (16 вокселей на ячейку);
- звери, поведение которых выводится из свойств вида (заяц, белка, кошка, олень, волк);
- пиксельный интерфейс по макетам (plan/design/ui.md): время, срез уровней, панель с руками и блоками,
  меню паузы, статистика производительности; раскладка подстраивается под пропорции экрана и
  переключается между сенсором и мышью по последнему вводу.

### Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить |
| Пробел | прыжок |
| ЛКМ / ПКМ | копать / поставить блок |
| 1–7, колесо | выбрать блок |
| Q / E | срез уровней вниз / вверх |
| R | вернуть срез к уровню игрока (на экране — тап по номеру уровня) |
| Z | следующий сезон |
| X | осадки |
| T | ускорить время |
| G | тени вкл/выкл |
| H | скрыть подсказку |
| F3 | статистика производительности |
| Esc | меню паузы (там же сезон, осадки, время, тени) |

На сенсорном экране: джойстик слева, справа кнопка действия (копать / ставить) и прыжок,
касание мира делает действие руки, выбранной на панели. Кнопка с графиком вверху открывает
статистику (FPS, время кадра, фризы, просадки, отрисовка), кнопка меню ставит игру на паузу.

## Разработка

- Движок: Godot 4.5 (рендерер Compatibility, чтобы работать в браузере).
- Открыть проект: Godot → Import → `project.godot`.
- Тесты: `godot --headless --path . --script res://tests/run_tests.gd`; тест фризов (игра без экрана,
  предел времени кадра): `godot --headless --path . --script res://tests/frame_test.gd`.
- GitHub Actions на каждый пуш запускает тесты, собирает web-версию и публикует её на GitHub Pages
  (в настройках репозитория: Settings → Pages → Source: GitHub Actions).

### Структура

- `src/shared/`: данные мира, генератор, правила поведения, рейкаст (общее для клиента и будущего сервера).
- `src/client/`: рендер чанков, текстуры, спрайты, игрок, звери, интерфейс (`hud.gd`, `ui_style.gd`).
- `assets/fonts/`: пиксельный шрифт Press Start 2P (лицензия OFL).
- `shaders/`: шейдеры мира (кромки, переходы, срез, снег, мокрость, сезоны), воды, травы, крон, спрайтов,
  частиц и цветокора; общий код в `common.gdshaderinc`.
- `tests/`: headless-тесты (`run_tests.gd` — проверки данных и мешей, `frame_test.gd` — фризы,
  `browser_smoke.mjs` — запуск web-сборки в Chrome на CI).
- `tools/shot.gd`: скриншоты сцен (день, вечер, ночь, дождь, осень, зима, пещера, берег) без браузера:
  `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 --script res://tools/shot.gd -- /tmp/shots`.
