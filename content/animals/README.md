# Мод «Звери»

Заяц, белка, дикая кошка, олень и волк. Раньше они были частью основы (`content/core`), а их
картинки рисовались кодом клиента; теперь это отдельный мод из данных и пяти PNG, как и
[«Птицы»](../birds/README.md). Выключите его на экране «Новый мир», и мир будет без зверей
(воробьи из «Птиц» останутся).

## Что в папке

```
content/animals/
  mod.yaml                      id: animals, requires: [core]
  data/creatures.yaml           пять видов и их свойства
  sprites/creatures/<вид>.png   картинка каждого вида, один кадр
  README.md                     этот файл
```

## Как он устроен

- `requires: [core]`: голоса зверей (`calls`, `alarm`) — записи звуков основы (`core:wolf_howl`),
  поэтому мод грузится после неё.
- Поведение не описано ни строчкой: кошка (4 кг, мясо) охотится на зайца и белку и боится волка,
  волк (40 кг) ночью ищет добычу, олень и заяц пасутся и убегают от людей — всё это правила
  `src/shared/game/wildlife.gd` и `src/shared/content/ai_rules.gd` по массе, рациону, зрению,
  скорости и `human_wariness` каждого вида.
- Картинки — пиксельные PNG с прозрачным фоном, зверь смотрит вправо (влево игра отражает сама),
  по одному кадру (`frames` не задан). Их можно перерисовать в любом редакторе; размер любой.
- Новый зверь: запись в `data/creatures.yaml` и картинка `sprites/creatures/<sprite>.png`. Чтобы он
  ходил стадом или спал на деревьях, хватит полей `flock` и `roost` (см. README «Птиц»).
- Проверка: `godot --headless --path . --script res://tools/validate.gd` проверяет поля, ссылки на
  звуки и что у каждого вида есть картинка; валидатор также грузит мод отдельно, только с основой.
