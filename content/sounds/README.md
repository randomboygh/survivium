# Мод «Звуки»

Звуки, у которых хозяин — сама игра, тремя бандлами: «Природа» (ветер, дождь, град, метель, вода,
огонь, сверчки, гром, сова), «Игрок» (шаги по траве, земле, камню, снегу и воде, гребок, прыжок,
приземление, всплеск, копание, удар по камню, блок поставлен, подбор, сделано, еда, огонь зажжён)
и «Интерфейс» (кнопка, вкладка, окно). Каждый выключается на экране «Новый мир» отдельно. Звуки
вещей лежат у вещей: удар по стволу и шорох листвы — у древесины «Растений», стук по доскам — у
досок, взмах — у меча, покос — у косы, шаг по песку — у грунта, голоса и пение птиц — у зверей,
ноты музыки — в моде «Музыка».

## Что в папке

```
content/sounds/
  mod.yaml                  id: sounds, название, версия, api
  nature/ player/ ui/       бандл: bundle.yaml (название), data/sounds.yaml (записи), sounds/<id>.wav
                            или <id>_1.wav, <id>_2.wav ... — столько, сколько variants
  README.md                 этот файл
```

## Как он устроен

- Запись звука: `id`, `title`, `variants` (сколько файлов, каждый раз звучит случайный), `volume`,
  `loop`. Файлы собраны `tools/make_sounds.gd` из шума и тонов (`tools/sound/synth.gd`); любой можно
  заменить своим файлом с тем же именем.
- Код просит звук по имени без приставки мода (`play("rain")`, `Sound.resolve`): подойдёт запись
  с таким именем из любого загруженного бандла, последняя по порядку загрузки; нет её — тишина.
  Материалы называют свои звуки в `step` и `hit`, существа — в `calls` и `alarm`; ссылка на звук
  никого ни к кому не привязывает, выключенный бандл — просто тишина на его месте.
- Миры и настройки, где «Звуки» были одним модом, получают его три бандла и «Музыку» (`Mods.RENAMED`).
