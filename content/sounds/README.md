# Мод «Звуки»

Звуки природы (ветер, дождь, град, метель, вода, огонь, сверчки, гром, птицы, сова), шагов,
плавания и прыжков, работы (удар, копание, кошение, взмах, постановка блока, подбор, крафт, еда,
розжиг), интерфейса (щелчок, вкладка, окно) и ноты, из которых складывается музыка. Выключите мод на
экране «Новый мир», и мир замолчит — кроме голосов зверей и птиц, которые лежат в их модах.

## Что в папке

```
content/sounds/
  mod.yaml              id: sounds, requires: [core]
  data/sounds.yaml      записи звуков: название, число вариантов, громкость, петля
  data/materials.yaml   патчи материалам основы: звук шага (step) и удара (hit)
  sounds/<id>.wav       файлы, или <id>_1.wav, <id>_2.wav ... для звука с вариантами
  README.md             этот файл
```

## Как он устроен

- Игра просит звук **по имени без приставки мода**: `chop`, `rain`, `click`. Звучит запись с
  таким именем из последнего загруженного мода, где она есть; нет ни в одном — тишина. Поэтому
  звуковой пак — это мод, в котором файлы с теми же именами, а свой мод «Звуки» можно и выключить.
- Материалы основы звуков не знают: шаг (`step`) и удар (`hit`) им дописывает этот мод патчами в
  `data/materials.yaml` (`patch: true` меняет только названные поля). Голоса существ (`calls`,
  `alarm`) — записи их собственных модов («Звери», «Птицы»).
- Файлы собраны из шума и тонов командой `godot --headless --path . --script
  res://tools/make_sounds.gd -- [звук ...]` (`tools/sound/synth.gd`; таблица звуков и их модов в
  начале скрипта); любой можно заменить своим WAV с тем же именем — он перезапишется только при
  повторном запуске команды с его именем.
- Проверка: `godot --headless --path . --script res://tools/validate.gd` проверяет записи, ссылки
  на звуки у материалов и существ и что у каждой записи есть все файлы.
